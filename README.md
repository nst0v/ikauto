# ikauto.ru

Независимая статическая версия сайта `ikauto.ru`, пересобранная без Tilda. Изображения и шрифт хранятся локально. Видео RUTUBE загружаются только после согласия посетителя; ссылки на мессенджеры открываются по его явному действию.

## Запуск

```bash
npm install
npm run dev
```

Продакшен-сборка:

```bash
npm run build
npm run preview
```

Готовые файлы появятся в `dist/`.

## Формы

Без дополнительной настройки формы не передают персональные данные и честно предлагают позвонить. Чтобы отправлять заявки в российскую CRM или свой API, скопируйте `.env.example` в `.env` и укажите:

```dotenv
VITE_FORM_ENDPOINT=https://example.com/api/leads
```

Endpoint должен принимать `POST` с JSON, хранить данные в базе на территории РФ и сохранять доказательство согласия (`personalDataConsent`, `consentVersion`, `consentAt`, форма и страница). При подключении нового обработчика нужно актуализировать Политику и настройки CSP в `public/.htaccess`.

## Правовые страницы

- `/privacy.html` — политика обработки персональных данных;
- `/consent.html` — отдельное согласие на обработку;
- `/cookies.html` — cookie, Web Storage и RUTUBE;
- `/terms.html` — правовая информация и условия сайта.

Реквизиты оператора в документах нужно актуализировать сразу после получения подтверждённых ИНН, ОГРН/ОГРНИП, КПП, юридического адреса и рабочего email.
